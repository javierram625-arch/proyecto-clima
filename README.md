Este proyecto es una investigación interactiva sobre el punto de inflexión climático en México. 
A través de seis visualizaciones dinámicas, se analiza cómo la temperatura nacional ha roto con su promedio histórico, transformando anomalías estadísticas en un nuevo paradigma climático.

El proyecto guía al usuario desde un contexto global hasta un análisis detallado por ciudades mexicanas, utilizando técnicas de suavizado de datos (promedios móviles) para identificar el momento exacto en que el calentamiento se volvió estructural.


Dataset: Climate Change: Earth Surface Temperature Data
Proveedor: Berkeley Earth via Kaggle.
Fecha de descarga: 22 de abril de 2026.
